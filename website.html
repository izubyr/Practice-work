About This Page

This is a basic HTML page layout showing how the main structural elements of a webpage fit together: a navigator bar at the top, a header section for the page title, a main content area, and a footer at the bottom.

Why This Structure?

Using semantic tags like nav header main and footer makes your HTML easier to read, easier to style and more accessible to screen readers and search engines.

Key Elements Used

  • nav - groups the site's navigation links
  • header - introduces the page with a title and short summary
  • main - holds the primary content, unique to this page
  • section - breaks content into logical groups
  • footer - holds closing info like copyright and links
