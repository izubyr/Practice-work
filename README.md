# Web Development Fundamentals & Practice Lab

A collection of foundational web development exercises, core algorithm scripts, DOM manipulation projects, and semantic UI templates built during the introductory phase of learning front-end and core programming basics.

---

## 📌 Repository Overview

This repository documents hands-on practice across core web standards—progressing from basic HTML elements and CSS layouts to interactive vanilla JavaScript mechanics and algorithm problem solving.

### Key Focus Areas:
- **Semantic HTML5:** Forms, semantic sections (`<nav>`, `<header>`, `<main>`, `<footer>`), responsive tables, and typography elements.
- **CSS3 Layouts & Styling:** Flexbox navigation bars, CSS Grid cards/galleries, custom form styling, hover effects, and CSS keyframe animations.
- **JavaScript Core & Logic:** Array methods (`map`, `filter`, `reduce`), loops, conditional branching, basic math algorithms (primes, factors, angles), and object structures.
- **DOM Manipulation & Mini-Apps:** Event listeners, dynamic UI updates, interactive counters, CRUD array rendering, and game loops.

---

## 📂 Project & File Structure

### 🎮 Mini-Apps & Interactive Projects
- **`guess.html` / `ttt.html`**: Number guessing mini-games ("GuessMaster") featuring lives tracking, proximity hints, Enter-key submission, and game-reset state controls.
- **`stopwatch.html` / `stopwatch.js`**: Digital stopwatch tracking hours, minutes, and seconds using JavaScript interval timers.
- **`cars.html` / `script.js`**: Interactive vehicle management list with add, edit (`prompt`), and delete operations, alongside a basic BMI calculator prototype.
- **`counter.html` / `excercise.html`**: Click counter implementations practicing increment, decrement, reset, and DOM content replacement.

### 🎨 HTML & CSS Layouts
- **`website.html`**: A clean, responsive multi-section landing page demonstrating semantic layout structures, CSS grid cards, and multi-column footers.
- **`gallery.html`**: Responsive 4-column card grid gallery with hover elevation and box-shadow styling.
- **`navbar.html`**: Fixed top navigation bar styled with inline-block link items and hover states.
- **`box.html`**: CSS animation demonstration utilizing `@keyframes` background-color transitions and transform effects.
- **`table.html` / `page2.html`**: Complex table layouts testing `colspan`, `rowspan`, custom cell borders, and internal anchor navigation.
- **`forms.html` / `iii.html` / `external.css`**: Comprehensive form design examples including text inputs, phone/email types, radio selectors, checkboxes, select dropdowns, and styled textareas.

### 🧠 JavaScript & Scripting Exercises
- **`arrays.js`**: Fundamental array operations, loops (`for`, `for...of`), sum calculators, even-number filters, and maximum score lookups.
- **`exercise.js` / `map.js`**: Functional array transformations practicing `.map()`, `.filter()`, `.reduce()`, and deduplication.
- **`test.js`**: Extensive collection of introductory JavaScript logic—covering variable scope, operators, loops, string methods, functions, and elementary geometric/math algorithms.
- **`object.js`**: Basic object literal structures, key-value declarations, and property access.
- **`test.py`**: Introductory Python dictionary declaration and output.
